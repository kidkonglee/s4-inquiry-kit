## 使用與驗收

1. 教師開啟本機控制台，建立本節課堂，下載學生個別登入碼。
2. 學生開啟上述 GitHub Pages 網址；如果改用 ngrok 直接學案網址而看到提示頁，先按 Visit Site，再進入學案。
3. 學生填入課堂編號和自己的登入碼。示範模式不會傳資料給教師。
4. 確認學生端「已同步」、教師端看到實驗紀錄後才開始正式活動。
5. 下課確認待傳紀錄已補齊，再結束課堂、匯出及備份。

本次網路曾出現隧道心跳逾時和 HTTP 503，其後完整傳輸測試通過。因此不能只以一次成功認定足以穩定上課；請用校內平板連續測試，必要時改用另一個 Wi-Fi 或手機熱點比較。

MacBook 需要保持開機、連網且不進入睡眠。域名與額外學生個人資料都不是目前部署所必需。
